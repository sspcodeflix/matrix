TC-SD-101 / r3 · FR-SD-101

A requester cannot approve their own request from either the request page or a direct approval URL

Accepted · Passed · DEMO-RUN-032

Preconditions: A fictional pending request belongs to the current requester. The approval URL is supplied by a fixture, never guessed.

Role: requester · Data need: request.pending.owned-by-current-user

  1. Sign in as the requester test role and open the owned pending request.

    Expected: The request details are visible and the Approve control is absent.

  2. Open the fixture-provided approval URL for the same request.

    Expected: Access is denied; the request remains pending.

  3. Read the request state through the approved test fixture.

    Expected: No approval decision or approver has been recorded.

  4. Open the audit entry for the denied attempt as an authorized auditor.

    Expected: The attempt is recorded as denied without any approval event.

Harbor service request rules
