How credentials are handled

  • Passwords and MFA seeds stay in the vault. Matrix stores only the reference.
  • Identities exist in test environments only. Production sign-in is blocked.
  • Every sign-in is written to the audit log with the run that used it.
  • Tests declare a role, for example @role("ops-checker"), never an account.
